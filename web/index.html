              Trust your Mac’s certificate
              
            
            

              
Removes the browser warning and lets Shortcuts / HTTP Shortcuts connect. It only works for local network addresses.

              
Android: download the certificate, then Settings → Security → Encryption & credentials → Install a certificate → CA certificate.

              
iPhone: on the Mac choose Send Certificate via AirDrop, or download the profile. Then Settings → General → VPN & Device Management → install, and Settings → General → About → Certificate Trust Settings → turn it on.

              
Check it is really your Mac’s: the SHA‑256 fingerprint must start and end with the characters shown under the QR code on your Mac.
